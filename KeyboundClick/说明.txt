键影随行 0.2.1（实机候选版）

插件启动或重载时不弹窗；之后进入魔光键影自动显示，离开自动隐藏。
任何地点都可用 /ktgclick 手动打开设置；副本外不执行提交。

- 高分策略：屏障 > 紧急读条 > 魔法罐 > 近敌 > 首领；死亡词条仅在其他目标之后用于补分。
- 提交一次：一次点击只提交一个词条；在途提交、冷却或场景变化时不排队。
- 自动高分提交：首次默认关闭，之后保存选择。不是固定盲发，而是等待上次提交效果后再计时。
- 效果确认：观察血量、词条、读条、目标消失或分数变化。返回匹配只表示调用结果，不直接算成功。
- 停顿保护：一次超过时限未确认会退避，连续三次未确认后暂停自动执行；重新切换自动模式可复位。
- 1 秒提交保护：默认开启，可关闭并保存；手动、自动和可选的错误防闲置提交共用此设置。
- 基础延迟：保护开启时为 1000～10000 毫秒，关闭后为 100～10000 毫秒；每轮在 80%～120% 随机，从效果确认后开始计时。
- 安全门控：停止输入技能落地前及效果期间全部停手；前置阈值和读条后等待可通过滑条调整，默认 1800 / 3500 毫秒，修改立即生效并保存；游戏输入许可、锁定秒数、确认框、其他输入焦点和禁止输入状态优先。
- 防闲置：新配置默认关闭；旧配置的错误输入方式迁移为功能键与方向键。仅自动模式、游戏前台且确有空闲时运行。
- 防闲置仍可选“错误输入 1 + Enter”，但可能影响正确率；中断时若残留数字 1，请手动清空。
- 自动确认魔光键影“出发”和结算“退出”：独立开关默认开启，关闭窗口仍有效；排队仍由你发起。
- 自动诊断：提交、效果、未匹配、停顿、安全状态和异常写入 pluginConfigs\KeyboundClick\diagnostics 下的 JSONL 文件。

当前适配：国服客户端与 Dalamud API 15。
提交、实体收集、读条和分数四组特征码已在版本标记 2026.10.06.0000.0000 的本地客户端中唯一匹配；启动时任一签名不匹配都会禁用提交。
禁止打字状态 ID 5347；停止输入动作 ID 49529、49532、49702。
原生结构参考 AtmoOmen/FFXIVClientStructs.Expansion 提交 22b9e96bca56aab9d18a60956dfb71c14d3c50c2。

构建：在仓库根目录运行
  dotnet restore KeyboundCompanion.slnx --locked-mode
  dotnet build KeyboundCompanion.slnx -c Release --no-restore
  dotnet run --project KeyboundClick.Tests/KeyboundClick.Tests.csproj -c Release --no-build

开发模式加载 KeyboundClick/bin/x64/Release/KeyboundClick.dll。
同目录的 KeyboundClick.json 由 Dalamud.NET.Sdk 自动生成。
发布包位于 KeyboundClick/bin/x64/Release/KeyboundClick/latest.zip。

离线测试和 Release 构建已通过；整局实机稳定性、防闲置与高分收益仍需验收。
